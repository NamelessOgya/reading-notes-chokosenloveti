# フローネットワーク（Flow Network）入門
〜 「水道管のルール」から理解する、生成AI（GFlowNet）の超重要コンセプト 〜

---

## 1. はじめに：一言でいうと何？

**フローネットワーク（Flow Network）** とは、コンピュータサイエンスや数学（グラフ理論）で使われる、
> **「網の目のようにつながった水道管（パイプ）を、水がどう流れるかをモデル化したもの」**

です。

日常の身近な例で言えば、
- 家中の水道管（水源から蛇口まで）
- 道路の交通網（高速道路の料金所から出口までの車の流れ）
- インターネットの通信パケット（送信サーバーから受信スマホまでのデータ量）

などがすべてフローネットワークです。

そして、深層学習の最先端（**GFlowNet: Generative Flow Network**）では、この **「水がパイプを枝分かれしながら流れていく仕組み」** を応用して、**創薬のための新しい分子や新材料を自動生成するAI** が作られています。

---

## 2. フローネットワークの基本用語（高校生向け）

水道管のピタゴラスイッチを想像してみてください。

```
 (水源 s) ────> [ 分岐点 u ] ────> [ 分岐点 v ] ────> (排水口 t)
   [源点]           [中間ノード]         [中間ノード]          [沈点]
```

1. **ノード（頂点・節点）**: 水道管の **「継ぎ手（分岐点や合流点）」**。
2. **エッジ（辺）**: 水が流れる **「パイプ（有向パイプ）」**。水が逆流しないように矢印の向きが決まっています。
3. **源点（Source / ソース $s$）**: 水がコンコンと湧き出る **「水源（大元）」**。
4. **沈点（Sink / シンク $t$）**: 水が流れ込んで吸い込まれる **「排水口（ゴール）」**。
5. **フロー（Flow $F$）**: そのパイプの中を **実際に流れている水の量（流量）**。

---

## 3. たった1つの超重要ルール：「フロー保存則」

フローネットワークを理解する上で、覚えておくべき物理法則は **たった1つ** だけです。

### 💧 フロー保存則（キルヒホッフの法則の水バージョン）
> **「途中の分岐点では、水が勝手に消えたり増えたりしない」**  
> すなわち、**「ある交差点に入ってくる水の総量 ＝ 出ていく水の総量」**

数式で書くと、どの途中ノード $v$（水源と排水口以外）でも、以下の等式が必ず成り立ちます：

$$ \sum_{u} F(u \to v) = \sum_{w} F(v \to w) $$

- 左辺：上流のいろんなパイプ $u$ から、合流点 $v$ に **流れ込んでくる水の合計**
- 右辺：合流点 $v$ から、下流のいろんなパイプ $w$ へ **流れ出ていく水の合計**

当たり前ですよね！ パイプの途中に穴が空いていなければ、入った分の水はすべて別のパイプへ出ていくしかありません。

## 4. なぜこれが AI（分子生成 / GFlowNet）と関係あるの？

ここからが、論文 **「GFlowNet（Generative Flow Network）」** の核心です。  
世界的なAI研究者 Yoshua Bengio らは、**「分子や化合物を組み立てる工程」を、この水道管ネットワークにそっくりそのまま当てはめました**。

### 4-1. 分子づくりを「水の迷路」と見立てる

薬になる新しい分子を作るとき、原子を1個ずつつなぎ合わせていきます。
これをグラフで表すと、巨大な **有向非巡回グラフ（DAG: 逆戻りしない一方通行の迷路）** になります。

```
 (スタート: 空っぽの原子 s₀) ──【水源】
       │
       ├─→ [ 炭素 C を1個くっつける ]
       │         │
       │         ├─→ [ 酸素 O をくっつける ] ──→ (完成！ 分子A) ──【排水口 A】
       │         │
       │         └─→ [ 窒素 N をくっつける ] ──→ (完成！ 分子B) ──【排水口 B】
       │
       └─→ [ ベンゼン環をくっつける ] ───────→ (完成！ 分子C) ──【排水口 C】
```

- **水源 $s_0$**: 何もない初期状態（空っぽの原子）。
- **途中のパイプ**: 「原子を1つくっつける」「結合を増やす」という操作（アクション）。
- **排水口（ゴール $x$）**: 組み立てが終わって **「完成した分子 $x$」**。

### 4-2. ここで「報酬（薬としての効果）」を水にする！
完成した分子 $x$ には、創薬AIによって **「薬としての効果（報酬 $R(x)$）」** がスコアとして付けられます。
- 分子A: 報酬 $R(A) = 100$ 点（すごく効く特効薬！）
- 分子B: 報酬 $R(B) = 1$ 点（全然効かない失敗作）
- 分子C: 報酬 $R(C) = 50$ 点（そこそこ効く薬）

GFlowNet は、**「それぞれの排水口から流れ出る水の量を、その分子の報酬 $R(x)$ とぴったり同じにする」** ようにパイプの太さを調整します。

$$ \text{排水口 } x \text{ から出る水量 } = R(x) $$

## 5. GFlowNet の奇跡：なぜ「多様な分子」が作れるのか？

水道管のルール（フロー保存則）を守りながら、排水口から $R(x)$ の水が流れるようにパイプ網全体を学習させたとします。

すると、**水源 $s_0$ から流れ出た水滴が、途中の分岐点にさしかかったとき、どう動くでしょうか？**

### 分岐点での水滴の気持ち（確率的サンプリング）
交差点にやってきた水滴は、**「流れている水の量が多いパイプ（太いパイプ）」** の方へ吸い込まれやすくなります。

- 下流に「100点の特効薬A」があるパイプには、大量の水（100リットル）が流れているので、水滴は **高い確率でそっちへ流れていく**。
- 下流に「1点の失敗作B」があるパイプには、チョロチョロとしか水（1リットル）が流れていないので、水滴は **滅多にそっちへ行かない**。

その結果、水滴が最終的にどのゴール（排水口 $x$）にたどり着くかの確率は、**「その分子の報酬 $R(x)$ に完全に比例」** します！

$$ P(\text{分子 } x \text{ が完成する確率}) \propto R(x) $$

## 6. 通常の強化学習（RL）や MCMC と何が違うのか？

ここが手法の本質を理解する上で最も重要なポイントです。

| 手法 | どうやって分子を探すか？ | 最大の弱点 |
| :--- | :--- | :--- |
| **通常の強化学習 (RL)** | **「一番点数が高い1つの分子」だけを血眼になって探す** | 同じような分子ばかり何回も作ってしまい、**多様性（バリエーション）がない**（局所解にハマる）。 |
| **MCMC (モンテカルロ法)** | 完成した分子を少しずつ壊して作り直す（試行錯誤の往復） | 分子の形が大きく違う別の特効薬を見つけるのに、何万回も行ったり来たりして **計算時間がかかりすぎる**。 |
| **GFlowNet (フローネットワーク)** | **水が上流から下流へサラサラと流れるように、枝分かれしながら確率的に生成する** | 1回のパス（非反復）で、**「いろんな種類の高報酬な分子」をバランスよく大量に生み出せる！** |

### 💡 創薬で「多様性（バリエーション）」が命な理由
薬の開発では、コンピュータ上で「最高得点の分子」を1個だけ見つけても意味がありません。実際に試験管で実験すると「毒性があった」「水に溶けなかった」などの理由で 99% がボツになるからです。

だからこそ、**「構造が全然違う、でもどれも高得点な分子の候補」を 1,000 種類くらい手元に欲しい** のです。  
その理想を叶えたのが、フローネットワークの保存則をAIに組み込んだ **GFlowNet** です。

## 7. まとめ（論文を読み解くためのエッセンス）

1. **フローネットワークとは**:
   - 水道管のように、水が上流（水源）から下流（排水口）へ流れるネットワーク。
2. **フロー保存則**:
   - 途中のどの交差点でも、**「入ってくる水量 ＝ 出ていく水量」**。水は勝手に消えない。
3. **GFlowNet での応用**:
   - 分子のパーツを組み立てる分岐を有向グラフと見なし、完成した分子の報酬 $R(x)$ に見合う水を流す。
4. **最大の強み**:
   - 報酬が高い分子ほどたくさん生成されつつ、水がいろんな枝に分流するため、**「いろんなタイプの有望な分子（多様な候補）」を一発で直接生成できる**。
