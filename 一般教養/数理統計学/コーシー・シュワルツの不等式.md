# コーシー・シュワルツの不等式

## 結論（3行まとめ）

1. **確率変数 $X, Y$ について $\bigl(E[XY]\bigr)^2 \le E[X^2]\,E[Y^2]$ が成り立ちます。** 等号が成り立つのは、$X$ が $Y$ の定数倍になっているとき（$X = cY$）だけです。
2. **証明は、$E[(X - tY)^2] \ge 0$ を $t$ の2次式と見て、判別式 $\le 0$ を使うだけです。** 高校の2次不等式の知識で証明できます。
3. **統計では、「相関係数が $-1$ 以上 $1$ 以下である」ことの根拠になります。** 数列版・積分版・ベクトルの内積版も同じ不等式です。

---

## 1. 不等式の形

### 1-1. 確率変数版（統計で使う形）

$$
\boxed{\ \bigl(E[XY]\bigr)^2 \le E[X^2]\,E[Y^2]\ }
$$

### 1-2. 同じ不等式のいろいろな顔

| 名前 | 式 |
| --- | --- |
| 数列版 | $\displaystyle\left(\sum_{i=1}^n a_i b_i\right)^2 \le \left(\sum_{i=1}^n a_i^2\right)\left(\sum_{i=1}^n b_i^2\right)$ |
| 積分版 | $\displaystyle\left(\int f(x)g(x)\,dx\right)^2 \le \int f(x)^2\,dx\int g(x)^2\,dx$ |
| ベクトル版 | $\lvert\vec{a}\cdot\vec{b}\rvert \le \lvert\vec{a}\rvert\,\lvert\vec{b}\rvert$ |
| 共分散版 | $\bigl(\mathrm{Cov}(X, Y)\bigr)^2 \le V[X]\,V[Y]$ |

> [!NOTE]
> 数列版は、確率変数版で $X$ が値 $a_i$ を、$Y$ が値 $b_i$ を、それぞれ確率 $\frac{1}{n}$ でとる場合です（両辺に $\frac{1}{n^2}$ が付くだけで同じ式になります）。積分版は、連続分布で期待値を積分に直したものです。

### 1-3. 数値で確かめる

$a = (1, 2, 3)$、$b = (4, 5, 6)$ とすると、

- 左辺：$(1\cdot4 + 2\cdot5 + 3\cdot6)^2 = 32^2 = 1024$
- 右辺：$(1+4+9)(16+25+36) = 14 \times 77 = 1078$

$1024 \le 1078$ で成り立っています。$b = (2, 4, 6)$（$a$ の2倍）にすると、左辺 $= 28^2 = 784$、右辺 $= 14 \times 56 = 784$ で、等号になります。

---

## 2. 証明（判別式を使う）

### 2-1. 考え方

次の量は「2乗の期待値」なので、**どんな実数 $t$ でも $0$ 以上**です。

$$
q(t) = E\bigl[(X - tY)^2\bigr] \ge 0
$$

### 2-2. 手順

**① $q(t)$ を展開する**

$$
q(t) = E[X^2] - 2t\,E[XY] + t^2\,E[Y^2]
$$

**② $t$ の2次式と見る**

$E[Y^2] > 0$ とします。$q(t)$ は「$t^2$ の係数が正の2次式」で、**すべての $t$ で $0$ 以上**です。つまり $t$ 軸の下にもぐらないので、判別式は $0$ 以下になります。

**③ 判別式 $\le 0$ を書く**

$$
D/4 = \bigl(E[XY]\bigr)^2 - E[X^2]\,E[Y^2] \le 0
$$

これが示したかった不等式です。$\blacksquare$

> [!NOTE]
> $E[Y^2] = 0$ のときは、$Y = 0$（確率 $1$）なので、両辺とも $0$ になって成り立ちます。

### 2-3. 図で確かめる

![q(t)=E[(X-tY)^2] のグラフ。ふつうは t 軸に触れず、等号のときは1点で接し、不等式が成り立たないと t 軸の下にもぐってしまう。右は内積の図](./images/cauchy_schwarz.png)

- **左**：$q(t)$ のグラフです。
  - **青**（ふつう）：$t$ 軸に触れない。判別式 $< 0$。
  - **緑**（等号）：$t$ 軸にちょうど1点で接する。判別式 $= 0$。
  - **赤の破線**（あり得ない）：$t$ 軸の下にもぐる。$E[(X - tY)^2] < 0$ になってしまうので、起こり得ません。
- **右**：ベクトルの内積の図です（4 で説明します）。

### 2-4. 等号の成り立つ条件

等号 $D = 0$ のとき、$q(t)$ は $t$ 軸にちょうど1点 $t_0$ で触れます。つまり

$$
E\bigl[(X - t_0Y)^2\bigr] = 0 \quad\Longrightarrow\quad X = t_0Y \quad(\text{確率 } 1)
$$

**等号が成り立つのは、$X$ が $Y$ の定数倍のとき**だけです（逆に、$X = cY$ なら等号が成り立つのは直接計算で確かめられます）。

## 3. 共分散・相関係数への応用

### 3-1. $|\mathrm{Cov}(X,Y)| \le \sigma_X\sigma_Y$

$X$ と $Y$ の代わりに、平均を引いた $X - \mu_X$ と $Y - \mu_Y$ に適用すると、

$$
\bigl(E[(X-\mu_X)(Y-\mu_Y)]\bigr)^2 \le E[(X-\mu_X)^2]\,E[(Y-\mu_Y)^2]
\quad\Longleftrightarrow\quad
\bigl(\mathrm{Cov}(X,Y)\bigr)^2 \le V[X]\,V[Y]
$$

### 3-2. 相関係数は $-1$ 以上 $1$ 以下

両辺を $V[X]V[Y]$ で割って平方根をとると、

$$
\rho = \frac{\mathrm{Cov}(X,Y)}{\sqrt{V[X]\,V[Y]}} \quad\text{について}\quad -1 \le \rho \le 1
$$

等号 $\rho = \pm1$ になるのは、$X - \mu_X$ が $Y - \mu_Y$ の定数倍のとき、つまり**$X$ と $Y$ が直線の関係にある**ときです。詳しくは [共分散と相関係数](./共分散と相関係数.md) にまとめています。

---

## 4. 幾何学的な意味（内積）

2つのベクトル $\vec{a}, \vec{b}$ の内積は、なす角を $\theta$ として

$$
\vec{a}\cdot\vec{b} = \lvert\vec{a}\rvert\,\lvert\vec{b}\rvert\cos\theta
$$

です。$\lvert\cos\theta\rvert \le 1$ なので、$\lvert\vec{a}\cdot\vec{b}\rvert \le \lvert\vec{a}\rvert\lvert\vec{b}\rvert$ が成り立ちます。これがコーシー・シュワルツの不等式です。上の図の右側が、その様子です。

| ベクトルの世界 | 確率変数の世界 |
| --- | --- |
| 内積 $\vec{a}\cdot\vec{b}$ | $E[XY]$ |
| 長さの2乗 $\lvert\vec{a}\rvert^2$ | $E[X^2]$ |
| $\cos\theta$ | $\dfrac{E[XY]}{\sqrt{E[X^2]E[Y^2]}}$ |
| $\cos\theta = \pm1$（平行） | $X = cY$（等号） |

**平均を引いた変数どうしでは、この $\cos\theta$ が相関係数 $\rho$ にあたります**。「相関係数＝2つの確率変数のなす角のコサイン」と覚えると、$-1 \le \rho \le 1$ は当たり前に思えます。

## 5. よく使う応用

### 5-1. $E[X]^2 \le E[X^2]$（$Y = 1$ とおく）

$Y = 1$ とすると $E[XY] = E[X]$、$E[Y^2] = 1$ なので、

$$
\bigl(E[X]\bigr)^2 \le E[X^2]
$$

これは $V[X] = E[X^2] - (E[X])^2 \ge 0$ と同じ内容です。[凸関数とイェンセンの不等式](../微積分/凸関数とイェンセンの不等式.md)で $f(x) = x^2$ とした場合でもあります。

### 5-2. $E[X]\,E[1/X] \ge 1$（$X > 0$）

$\sqrt{X}$ と $\dfrac{1}{\sqrt{X}}$ に適用します。積 $\sqrt{X}\cdot\dfrac{1}{\sqrt{X}} = 1$ なので、

$$
1 = \Bigl(E\Bigl[\sqrt{X}\cdot\tfrac{1}{\sqrt{X}}\Bigr]\Bigr)^2 \le E[X]\,E\!\left[\frac{1}{X}\right]
$$

### 5-3. 和の不等式

$a_i > 0$ について、数列版で $a_i \to \sqrt{a_i}$、$b_i \to \dfrac{1}{\sqrt{a_i}}$ とすると、

$$
(a_1 + \cdots + a_n)\left(\frac{1}{a_1} + \cdots + \frac{1}{a_n}\right) \ge n^2
$$

（相加平均 $\ge$ 調和平均 の形です）。

### 5-4. 一般化：ヘルダーの不等式

$\dfrac1p + \dfrac1q = 1$ ($p, q > 1$) のとき、

$$
E\lvert XY\rvert \le \bigl(E\lvert X\rvert^p\bigr)^{1/p}\bigl(E\lvert Y\rvert^q\bigr)^{1/q}
$$

$p = q = 2$ がコーシー・シュワルツの不等式です。

---

## 6. 試験での使い方

- **「相関係数が $-1$ 以上 $1$ 以下であることを示せ」** → $X - \mu_X$ と $Y - \mu_Y$ にコーシー・シュワルツを適用する（3-1）。または次の2次式を使う。
  $$E\bigl[\bigl((X-\mu_X) - t(Y - \mu_Y)\bigr)^2\bigr] = V[X] - 2t\,\mathrm{Cov}(X,Y) + t^2V[Y] \ge 0$$
- **証明を書くとき**：「$t$ の2次式が常に $0$ 以上なので判別式 $\le 0$」と書く。**$E[Y^2] = 0$ の場合分け**は一言触れておくと丁寧です。
- **等号の条件**を聞かれたら、「$X = cY$（確率 $1$）」と答える。
- **不等式の評価**：$E[XY]$ が直接計算しにくいときに、$\sqrt{E[X^2]E[Y^2]}$ で上から押さえることができます。

---

## まとめ

- **主張**：$\bigl(E[XY]\bigr)^2 \le E[X^2]E[Y^2]$。等号は $X = cY$ のとき。
- **証明**：$E[(X - tY)^2] \ge 0$ を $t$ の2次式と見て、判別式 $\le 0$。
- **意味**：内積と同じ。平均を引いた変数では $\cos\theta$ が相関係数。
- **応用**：$-1 \le \rho \le 1$、$E[X]^2 \le E[X^2]$、$E[X]E[1/X] \ge 1$ など。
