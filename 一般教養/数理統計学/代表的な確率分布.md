# 代表的な確率分布

数理統計学でよく出てくる11個の分布について、**名前の由来・用途・確率（密度）関数・確率母関数・積率母関数・特性関数**をまとめます。
母関数そのものの意味は [確率母関数・積率母関数・特性関数](./確率母関数・積率母関数・特性関数.md) を参照してください。

## 結論（3行まとめ）

1. **離散分布は「ベルヌーイ試行（成功か失敗かの1回の試行）」から生まれます。** 何回中何回成功か → 二項分布、何回目で成功するか → 幾何分布・負の二項分布、まれな出来事の回数 → ポアソン分布。
2. **連続分布は「待ち時間」と「正規分布の2乗」から生まれます。** 1回目の待ち時間 → 指数分布、$\alpha$ 回目の待ち時間 → ガンマ分布、正規分布の2乗の和 → カイ二乗分布（ガンマ分布の特別な場合）。
3. **多くの分布は、極限をとると正規分布に近づきます**（中心極限定理）。

| 指数分布 | $Exp(\lambda)$ | $x \ge 0$ | $\dfrac{1}{\lambda}$ | $\dfrac{1}{\lambda^2}$ |
| ワイブル分布 | $W(k, \eta)$ | $x \ge 0$ | $\eta\,\Gamma\!\left(1+\frac{1}{k}\right)$ | $\eta^2\left[\Gamma\!\left(1+\frac{2}{k}\right) - \Gamma\!\left(1+\frac{1}{k}\right)^2\right]$ |
| ベータ分布 | $Be(\alpha, \beta)$ | $0 < x < 1$ | $\dfrac{\alpha}{\alpha+\beta}$ | $\dfrac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$ |

![代表的な確率分布の形](./images/distribution_shapes.png)

> [!NOTE]
> **記号の約束**
> - $\Gamma(\alpha) = \int_0^\infty x^{\alpha-1}e^{-x}\,dx$（ガンマ関数。整数なら $\Gamma(n) = (n-1)!$）
> - $B(\alpha, \beta) = \int_0^1 x^{\alpha-1}(1-x)^{\beta-1}\,dx = \dfrac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}$（ベータ関数）
> - 確率母関数 $G(s) = E[s^X]$、積率母関数 $M(t) = E[e^{tX}]$、特性関数 $\varphi(t) = E[e^{itX}]$
> - 3つの間には $M(t) = G(e^t)$、$\varphi(t) = M(it)$ の関係があります。
> - 確率母関数は本来、整数値をとる離散分布のためのものです。連続分布では $s > 0$ について $G(s) = M(\log s)$ と形式的に書けますが、ふつうは使いません。

## 2. 離散分布

### 2-1. 二項分布 $B(n, p)$

- **名前の由来**：確率 $P(X=k)$ が、二項定理 $(q + p)^n = \sum_k {}_n\mathrm{C}_k\, p^k q^{n-k}$ の各項になっているから（「二項」＝ $p$ と $q$ の2つの項）。
- **用途**：$n$ 回中の成功回数。コインの表の回数、不良品の個数、アンケートの「はい」の人数、A/Bテストのクリック数など。

| | 式 |
| --- | --- |
| 確率関数 | $P(X = k) = {}_n\mathrm{C}_k\, p^k q^{n-k} \quad (k = 0, 1, \dots, n)$ |
| 確率母関数 | $G(s) = (q + ps)^n$ |
| 積率母関数 | $M(t) = (q + pe^t)^n$ |
| 特性関数 | $\varphi(t) = (q + pe^{it})^n$ |

確率母関数が $(q + ps)^n$ ＝「1回分の母関数 $(q + ps)$ の $n$ 乗」になるのは、二項分布がベルヌーイ分布 $n$ 個の和だからです。

### 2-2. ポアソン分布 $Po(\lambda)$

- **名前の由来**：フランスの数学者**ポアソン**（S. D. Poisson）が1837年に二項分布の極限として導いたことから。
- **用途**：一定時間・一定範囲に**まれに起こる出来事の回数**。1時間の来店客数、1日の事故件数、1ページの誤植の数、Webサイトへの1分あたりのアクセス数など。平均＝分散 になるのが特徴です。

| | 式 |
| --- | --- |
| 確率関数 | $P(X = k) = e^{-\lambda}\dfrac{\lambda^k}{k!} \quad (k = 0, 1, 2, \dots)$ |
| 確率母関数 | $G(s) = e^{\lambda(s-1)}$ |
| 積率母関数 | $M(t) = e^{\lambda(e^t - 1)}$ |
| 特性関数 | $\varphi(t) = e^{\lambda(e^{it} - 1)}$ |

#### 証明：二項分布の極限がポアソン分布になる

**主張**：$k$ を固定し、$np = \lambda$（一定）を保ったまま $n \to \infty$ とすると、

$$
{}_n\mathrm{C}_k\, p^k (1-p)^{n-k} \;\longrightarrow\; e^{-\lambda}\frac{\lambda^k}{k!}
$$

**証明**：$p = \dfrac{\lambda}{n}$ を代入し、${}_n\mathrm{C}_k = \dfrac{n(n-1)\cdots(n-k+1)}{k!}$ を使って4つの部分に分けます。

$$
{}_n\mathrm{C}_k \left(\frac{\lambda}{n}\right)^k \left(1 - \frac{\lambda}{n}\right)^{n-k}
= \frac{\lambda^k}{k!}
\cdot \underbrace{\frac{n(n-1)\cdots(n-k+1)}{n^k}}_{(\mathrm{a})}
\cdot \underbrace{\left(1 - \frac{\lambda}{n}\right)^{n}}_{(\mathrm{b})}
\cdot \underbrace{\left(1 - \frac{\lambda}{n}\right)^{-k}}_{(\mathrm{c})}
$$

それぞれの極限を調べます。

- **(a) → 1**：分子の $k$ 個の因数を、分母の $n$ で1つずつ割ると
  $$
  \frac{n}{n} \cdot \frac{n-1}{n} \cdots \frac{n-k+1}{n} = 1 \cdot \left(1 - \frac{1}{n}\right) \cdots \left(1 - \frac{k-1}{n}\right)
  $$
  $k$ は固定なので、これは**決まった個数（$k$ 個）** の「$1$ に近づくもの」の積です。よって $1$ に近づきます。
- **(b) → $e^{-\lambda}$**：高校で習う極限 $\displaystyle\lim_{n \to \infty}\left(1 + \frac{x}{n}\right)^n = e^x$ で $x = -\lambda$ としたものです（この極限の一般化は [極限の公式まとめ](../極限/極限の公式まとめ.md) を参照）。
  （確認：対数をとると $n\log\left(1 - \frac{\lambda}{n}\right) \approx n \cdot \left(-\frac{\lambda}{n}\right) = -\lambda$。$\log(1+u) \approx u$ は $u$ が小さいときの[テイラー展開](../微積分/テイラー展開.md)による近似です。）
- **(c) → 1**：$1 - \frac{\lambda}{n} \to 1$ で、指数 $-k$ は固定なので、$1^{-k} = 1$ に近づきます。

以上をまとめると、

$$
\frac{\lambda^k}{k!} \cdot 1 \cdot e^{-\lambda} \cdot 1 = e^{-\lambda}\frac{\lambda^k}{k!}
$$

となり、ポアソン分布の確率関数が得られます。$\blacksquare$

> [!TIP]
> **ポイントは「$k$ を固定して $n$ だけを大きくする」こと**です。(a) と (c) が $1$ になるのは、$n$ に比べて $k$ が無視できるほど小さいからです。(b) だけが「$n$ 個の枠すべてで起こらない」確率として $e^{-\lambda}$ という意味のある値を残します。

**式の各部分の意味**

| 部分 | 意味 |
| --- | --- |
| $\lambda^k$ | $k$ 回の発生それぞれが確率 $\frac{\lambda}{n}$ で起こる（$\left(\frac{\lambda}{n}\right)^k$ の分子） |
| $\frac{1}{k!}$ | $k$ 回の発生の**並び順は区別しない**（${}_n\mathrm{C}_k$ の分母） |
| $e^{-\lambda}$ | 残りのほぼすべての枠で**何も起こらない** |

> [!NOTE]
> 確率母関数を使うと、もっと短く示せます（4 章も参照）。
> $$
> G_{B(n, \lambda/n)}(s) = \left(1 + \frac{\lambda(s-1)}{n}\right)^n \xrightarrow{n \to \infty} e^{\lambda(s-1)} = G_{Po(\lambda)}(s)
> $$
> 確率母関数が一致すれば分布も一致する（$s^k$ の係数が確率だから）ので、これで極限がポアソン分布であることがわかります。

### 2-3. 幾何分布 $Ge(p)$

- **名前の由来**：確率 $p, pq, pq^2, pq^3, \dots$ が**等比数列**（英語で geometric sequence＝幾何数列）になっているから。
- **用途**：初めて成功するまでの回数。ガチャで当たりが出るまでの回数、初めて故障するまでの日数（離散版）など。「**無記憶性**」（これまで何回失敗したかに関係なく、この先の分布は同じ）をもつ唯一の離散分布です。

ここでは **$X$ ＝ 初めて成功するまでの失敗回数**（$0, 1, 2, \dots$）とします。

| | 式 |
| --- | --- |
| 確率関数 | $P(X = k) = p\,q^k \quad (k = 0, 1, 2, \dots)$ |
| 確率母関数 | $G(s) = \dfrac{p}{1 - qs} \quad \left(\lvert s \rvert < \frac{1}{q}\right)$ |
| 積率母関数 | $M(t) = \dfrac{p}{1 - qe^t} \quad (t < -\log q)$ |
| 特性関数 | $\varphi(t) = \dfrac{p}{1 - qe^{it}}$ |

> [!WARNING]
> 教科書によっては **$Y$ ＝ 初めて成功するまでの試行回数**（成功した回も数える、$Y = X + 1 = 1, 2, \dots$）で定義します。その場合は $P(Y = k) = pq^{k-1}$、平均 $\frac{1}{p}$、$G(s) = \dfrac{ps}{1 - qs}$ です。試験ではどちらの定義か必ず確認してください。

### 2-4. 負の二項分布 $NB(r, p)$

- **名前の由来**：確率に出てくる係数 ${}_{r+k-1}\mathrm{C}_k$ が、**指数が負の二項展開** $(1 - q)^{-r} = \sum_k {}_{r+k-1}\mathrm{C}_k\, q^k$ の係数だから。$\sum_k P(X=k) = p^r(1-q)^{-r} = 1$ となります。（負の二項展開の詳しい説明は[一般化された二項定理](../微積分/一般化された二項定理.md)）
- **用途**：
  - $r$ 回成功するまでの失敗回数。
  - **ばらつきがポアソン分布より大きいカウントデータ**（過分散データ）のモデル。平均 $\frac{rq}{p}$ より分散 $\frac{rq}{p^2}$ が大きいので、「平均＝分散」のポアソン分布では合わない事故件数・購買回数・遺伝子発現量などに使います。

ここでは **$X$ ＝ $r$ 回成功するまでの失敗回数**とします。

| | 式 |
| --- | --- |
| 確率関数 | $P(X = k) = {}_{r+k-1}\mathrm{C}_k\, p^r q^k \quad (k = 0, 1, 2, \dots)$ |
| 確率母関数 | $G(s) = \left(\dfrac{p}{1 - qs}\right)^r$ |
| 積率母関数 | $M(t) = \left(\dfrac{p}{1 - qe^t}\right)^r \quad (t < -\log q)$ |
| 特性関数 | $\varphi(t) = \left(\dfrac{p}{1 - qe^{it}}\right)^r$ |

幾何分布の母関数の $r$ 乗になっているのは、負の二項分布が幾何分布 $r$ 個の和だからです。$r = 1$ なら幾何分布です。

### 2-5. 超幾何分布 $HG(N, K, n)$

- **名前の由来**：確率母関数が、ガウスの**超幾何級数**（hypergeometric series）で表されるから。超幾何級数は、等比級数（geometric series）を一般化した級数なので「超（hyper）＋幾何（geometric）」と呼ばれます。
- **用途**：**元に戻さずに取り出す**（非復元抽出）ときの当たりの数。$N$ 個中 $K$ 個が当たりの箱から $n$ 個取り出したときの当たりの個数、抜き取り検査、トランプの手札、フィッシャーの正確検定（2×2分割表の検定）、捕獲再捕獲法による個体数推定など。

| | 式 |
| --- | --- |
| 確率関数 | $P(X = k) = \dfrac{{}_K\mathrm{C}_k \cdot {}_{N-K}\mathrm{C}_{n-k}}{{}_N\mathrm{C}_n}$ |
| 確率母関数 | $G(s) = \displaystyle\sum_k P(X = k)\, s^k = \frac{{}_{N-K}\mathrm{C}_n}{{}_N\mathrm{C}_n}\; {}_2F_1(-n, -K;\ N-K-n+1;\ s)$ |
| 積率母関数 | $M(t) = G(e^t)$ |
| 特性関数 | $\varphi(t) = G(e^{it})$ |

${}_2F_1(a, b; c; s) = \displaystyle\sum_{m=0}^{\infty}\frac{(a)_m (b)_m}{(c)_m}\frac{s^m}{m!}$ はガウスの超幾何関数です（$(a)_m = a(a+1)\cdots(a+m-1)$）。閉じた式は $N - K \ge n$ のときの形です。実際の計算では、有限和 $\sum_k P(X=k)\,s^k$ のまま扱うのがふつうです。

分散の最後の因子 $\frac{N-n}{N-1}$ は**有限母集団修正**と呼ばれ、$N \to \infty$ で $1$ になって二項分布の分散 $npq$（$p = K/N$）に一致します。

## 3. 連続分布

### 3-1. 正規分布 $N(\mu, \sigma^2)$

- **名前の由来**：測定誤差や身長など、多くの現象で「**ふつうに（normal）**」現れる分布という意味で、19世紀後半に広まった呼び名です。誤差の理論を作ったガウスにちなんで**ガウス分布**とも呼ばれます。
- **用途**：測定誤差、身長・テストの点数などのモデル。**中心極限定理**により「たくさんの独立な要因の和」は正規分布に近づくので、平均値の検定・区間推定、回帰分析の誤差など、統計のほぼすべての場面の基本になります。

| | 式 |
| --- | --- |
| 確率密度関数 | $f(x) = \dfrac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\dfrac{(x-\mu)^2}{2\sigma^2}\right)$ |
| 確率母関数 | （ふつう使わない。形式的には $G(s) = \exp\left(\mu\log s + \frac{\sigma^2(\log s)^2}{2}\right)$、$s > 0$） |
| 積率母関数 | $M(t) = \exp\left(\mu t + \dfrac{\sigma^2 t^2}{2}\right)$ |
| 特性関数 | $\varphi(t) = \exp\left(i\mu t - \dfrac{\sigma^2 t^2}{2}\right)$ |

### 3-2. ガンマ分布 $Ga(\alpha, \lambda)$

- **名前の由来**：確率密度関数の全体を $1$ にするための定数に**ガンマ関数** $\Gamma(\alpha)$ が出てくるから。
- **用途**：**$\alpha$ 回目の出来事が起こるまでの待ち時間**（指数分布 $\alpha$ 個の和）。正の値をとる右に裾の長いデータ（降水量、保険金額、待ち時間）のモデル。ポアソン分布の $\lambda$ の共役事前分布（ベイズ統計）。

ここでは $\alpha$ を**形状**、$\lambda$ を**率**（scale $= 1/\lambda$）とします。

| | 式 |
| --- | --- |
| 確率密度関数 | $f(x) = \dfrac{\lambda^\alpha}{\Gamma(\alpha)}\, x^{\alpha-1} e^{-\lambda x} \quad (x > 0)$ |
| 確率母関数 | （ふつう使わない。形式的には $G(s) = \left(1 - \frac{\log s}{\lambda}\right)^{-\alpha}$、$0 < s < e^\lambda$） |
| 積率母関数 | $M(t) = \left(1 - \dfrac{t}{\lambda}\right)^{-\alpha} \quad (t < \lambda)$ |
| 特性関数 | $\varphi(t) = \left(1 - \dfrac{it}{\lambda}\right)^{-\alpha}$ |

> [!WARNING]
> 教科書によって $Ga(\alpha, \beta)$ の $\beta$ が「率 $\lambda$」のことも「尺度 $1/\lambda$」のこともあります。平均が $\alpha\beta$ なのか $\alpha/\beta$ なのかで見分けてください。

#### なぜ $x$ の指数が $\alpha$ ではなく $\alpha - 1$ なのか

**ポアソン分布から導くと自然に $-1$ が出てくるから**です（$\alpha = n$ が自然数の場合）。

1. 平均 $\lambda$ 回/単位時間のポアソン過程で、$n$ 回目が起きる時刻を $T_n$、$[0,x]$ での回数を $N(x)$ とします。
2. 「$n$ 回目が $x$ より後」＝「$x$ までに $n-1$ 回以下」なので
   $$P(T_n > x) = P(N(x) \le n-1) = \sum_{k=0}^{n-1} e^{-\lambda x}\frac{(\lambda x)^k}{k!}$$
3. これを微分して符号を変えると、隣どうしの項が打ち消し合って最後の項だけ残ります。
   $$f(x) = \lambda \cdot e^{-\lambda x}\frac{(\lambda x)^{n-1}}{(n-1)!} = \frac{\lambda^n}{(n-1)!}\,x^{n-1}e^{-\lambda x}$$
   「$x$ までに $n-1$ 回起きて（ポアソン確率）、時刻 $x$ で最後の1回が起きる（割合 $\lambda$）」という意味で、**$x^{n-1}$ の $-1$ は「それまでの $n-1$ 回」**に由来します。

   **（打ち消し合いの詳細）** $u = \lambda x$、$p_k = e^{-u}\dfrac{u^k}{k!}$ と略します（$\frac{d}{dx} = \lambda\frac{d}{du}$）。

   - **$k \ge 1$ の項**：積の微分と $\dfrac{k}{k!} = \dfrac{1}{(k-1)!}$ より
     $$\frac{d}{du}\left[e^{-u}\frac{u^k}{k!}\right] = e^{-u}\frac{u^{k-1}}{(k-1)!} - e^{-u}\frac{u^k}{k!} = p_{k-1} - p_k$$
   - **$k = 0$ の項**：$\frac{u^0}{0!} = 1$ は定数で、微分すると $0$ なので、**引く項だけ**が残ります（$p_{-1}$ は存在しない）。
     $$\frac{d}{du}e^{-u} = -p_0$$

   $n = 3$ で並べると、斜めに打ち消し合い、最後の $-p_2$ だけが残ります。**最初の項 $-p_0$ は、次の行の $+p_0$ を消す役**です。

   $$
   \begin{array}{rcrr}
   \frac{d}{du}p_0 &=& & -p_0 \\
   \frac{d}{du}p_1 &=& p_0 & -p_1 \\
   \frac{d}{du}p_2 &=& p_1 & -p_2 \\ \hline
   \text{合計} &=& & -p_2
   \end{array}
   $$

   直接計算でも確かめられます。かっこを微分すると、定数 $1$ が消えて1次数短くなるので、最後の項だけが残ります。
   $$\frac{d}{du}\left[e^{-u}\left(1 + u + \frac{u^2}{2}\right)\right] = e^{-u}(1 + u) - e^{-u}\left(1 + u + \frac{u^2}{2}\right) = -e^{-u}\frac{u^2}{2}$$

   一般の $n$ でも $\frac{d}{du}\sum_{k=0}^{n-1}p_k = -p_{n-1}$ となり、$f(x) = -\frac{d}{dx}P(T_n > x) = \lambda\,p_{n-1}$ が得られます。

4. 全確率 $=1$ と $\lambda = 1$ から $\displaystyle\int_0^\infty x^{n-1}e^{-x}\,dx = (n-1)!$。これを実数 $\alpha > 0$ に広げたものが**ガンマ関数** $\Gamma(\alpha) = \int_0^\infty x^{\alpha-1}e^{-x}\,dx$ です。

$\alpha - 1$ の形にしておくと、$\alpha$ が「何回目を待つか」と一致し、公式がきれいになります。

| 性質 | $\alpha$ で書く（$x^{\alpha-1}$） | $a = \alpha-1$ で書く（$x^a$） |
| --- | --- | --- |
| 指数分布 | $\alpha = 1$ | $a = 0$ |
| 平均・分散 | $\alpha/\lambda,\ \alpha/\lambda^2$ | $(a+1)/\lambda,\ (a+1)/\lambda^2$ |
| 再生性（和） | $\alpha_1 + \alpha_2$ | $a_1 + a_2 + 1$ |
| パラメータの条件 | $\alpha > 0$ | $a > -1$ |

> [!NOTE]
> ポアソン分布から導けるのは $\alpha$ が自然数のときだけです（「1.5回目」には意味がないため）。自然数でない $\alpha$ は、式の形を実数に広げたものです。ベータ分布の $x^{\alpha-1}(1-x)^{\beta-1}$ も同じ考え方です。

### 3-3. カイ二乗分布 $\chi^2(k)$

- **名前の由来**：統計学者**ピアソン**（K. Pearson）が1900年に、適合度を測る統計量をギリシャ文字 $\chi$（カイ）の2乗 $\chi^2$ で表したことから。中身が「標準正規分布の**2乗**の和」であることとも合っています。
- **用途**：適合度検定・独立性の検定（カイ二乗検定）、正規母集団の分散の区間推定・検定、尤度比検定の近似分布。$t$ 分布・$F$ 分布の材料にもなります。$k$ は**自由度**と呼びます。

| | 式 |
| --- | --- |
| 確率密度関数 | $f(x) = \dfrac{1}{2^{k/2}\,\Gamma(k/2)}\, x^{k/2 - 1} e^{-x/2} \quad (x > 0)$ |
| 確率母関数 | （ふつう使わない。形式的には $G(s) = (1 - 2\log s)^{-k/2}$、$0 < s < \sqrt{e}$） |
| 積率母関数 | $M(t) = (1 - 2t)^{-k/2} \quad \left(t < \frac{1}{2}\right)$ |
| 特性関数 | $\varphi(t) = (1 - 2it)^{-k/2}$ |

$\chi^2(k) = Ga\left(\frac{k}{2}, \frac{1}{2}\right)$ なので、式はすべてガンマ分布に $\alpha = k/2$、$\lambda = 1/2$ を代入したものです。$\chi^2(2) = Exp(1/2)$ でもあります。

#### なぜ $Ga\left(\frac{k}{2}, \frac{1}{2}\right)$ になるのか

2段階で理解できます：**① $Z^2$ 1個が $Ga\left(\frac12, \frac12\right)$**、**② ガンマ分布は足すと $\alpha$ が足し算される（再生性）**。

**① $Z^2$ の密度を求める**（$Z \sim N(0,1)$、$Y = Z^2$、$y > 0$）

$$P(Y \le y) = P(-\sqrt{y} \le Z \le \sqrt{y}) = 2\Phi(\sqrt{y}) - 1$$

$y$ で微分すると、合成関数の微分で $(\sqrt{y})' = \frac{1}{2\sqrt{y}}$ が出ます（$\varphi$ は標準正規分布の密度）。

$$f_Y(y) = 2\varphi(\sqrt{y})\cdot\frac{1}{2\sqrt{y}} = \frac{1}{\sqrt{2\pi}}\, y^{-1/2}\, e^{-y/2}$$

ガンマ分布 $\dfrac{\lambda^\alpha}{\Gamma(\alpha)}\, y^{\alpha-1}\, e^{-\lambda y}$ と見比べると：

| 部分 | 対応 | 結果 | どこから来たか |
| --- | --- | --- | --- |
| $e^{-\lambda y}$ | $e^{-y/2}$ | $\lambda = \frac12$ | 正規分布の $e^{-z^2/2}$ の「$\frac12$」 |
| $y^{\alpha-1}$ | $y^{-1/2}$ | $\alpha = \frac12$ | 2乗を戻すときの微分 $\frac{1}{2\sqrt{y}}$ |
| 定数 | $\frac{(1/2)^{1/2}}{\Gamma(1/2)} = \frac{1}{\sqrt{2}\sqrt{\pi}}$ | 一致 | $\Gamma\left(\frac12\right) = \sqrt{\pi}$ |

よって $Z^2 \sim Ga\left(\frac12, \frac12\right) = \chi^2(1)$ です。

> [!NOTE]
> $y^{-1/2}$ は $y \to 0$ で無限大になります。$0$ 付近の $Z$ が2乗で $0$ のごく近くに押し込められるため、密度が高くなるのです。

**② 再生性で $k$ 個足す**

独立な和の積率母関数は掛け算になるので、

$$\underbrace{(1 - 2t)^{-1/2} \times \cdots \times (1 - 2t)^{-1/2}}_{k\text{ 個}} = (1 - 2t)^{-k/2}$$

これは $Ga\left(\frac{k}{2}, \frac12\right)$ の積率母関数なので、$Z_1^2 + \cdots + Z_k^2 \sim Ga\left(\frac{k}{2}, \frac12\right)$ です。

**直感**：ガンマ分布の $\alpha$ を「何回目の事象を待つか」と見ると、

- $Z^2$ 1個は「**事象 $\frac12$ 回分**」の待ち時間。
- 2個で「1回分」＝ $\chi^2(2) = Exp\left(\frac12\right)$。平面上の標準正規分布の点 $(Z_1, Z_2)$ の原点からの距離の2乗が指数分布になる、という有名な事実です。
- 自由度 $k$ が奇数だと $\alpha$ が半端な値になります。これが、ガンマ分布を自然数以外の $\alpha$ に広げておく理由の一つです。

### 3-4. 指数分布 $Exp(\lambda)$

- **名前の由来**：確率密度関数が**指数関数** $e^{-\lambda x}$ の形だから。
- **用途**：**次の出来事が起こるまでの待ち時間**。客の到着間隔、電話の通話時間、電子部品の寿命（偶発故障）、放射性元素の崩壊までの時間など。幾何分布の連続版で、**無記憶性** $P(X > s + t \mid X > s) = P(X > t)$ をもつ唯一の連続分布です。

| | 式 |
| --- | --- |
| 確率密度関数 | $f(x) = \lambda e^{-\lambda x} \quad (x \ge 0)$ |
| 確率母関数 | （ふつう使わない。形式的には $G(s) = \dfrac{\lambda}{\lambda - \log s}$、$0 < s < e^\lambda$） |
| 積率母関数 | $M(t) = \dfrac{\lambda}{\lambda - t} \quad (t < \lambda)$ |
| 特性関数 | $\varphi(t) = \dfrac{\lambda}{\lambda - it}$ |

$Exp(\lambda) = Ga(1, \lambda)$ です。

### 3-5. ワイブル分布 $W(k, \eta)$

- **名前の由来**：スウェーデンの技術者**ワイブル**（W. Weibull）が1951年に、材料の強度や寿命のデータに広く当てはまる分布として紹介したことから。
- **用途**：**信頼性工学・寿命データ**の標準的な分布。形状 $k$ で故障の起こり方を表せます。
  - $k < 1$：時間とともに故障しにくくなる（初期故障）
  - $k = 1$：故障のしやすさが一定（偶発故障）＝ 指数分布
  - $k > 1$：時間とともに故障しやすくなる（摩耗故障）

  ほかに風速の分布（風力発電の見積もり）などにも使われます。

ここでは $k$ を**形状**、$\eta$ を**尺度**とします。

| | 式 |
| --- | --- |
| 確率密度関数 | $f(x) = \dfrac{k}{\eta}\left(\dfrac{x}{\eta}\right)^{k-1} \exp\left[-\left(\dfrac{x}{\eta}\right)^k\right] \quad (x \ge 0)$ |
| 確率母関数 | （ふつう使わない。形式的には $G(s) = M(\log s)$） |
| 積率母関数 | 閉じた形では書けない。$k \ge 1$ のとき $M(t) = \displaystyle\sum_{n=0}^{\infty}\frac{(\eta t)^n}{n!}\,\Gamma\!\left(1 + \frac{n}{k}\right)$（$k = 1$ では $\lvert t \rvert < 1/\eta$ で収束）。$k < 1$ では $t > 0$ で存在しない |
| 特性関数 | 閉じた形では書けない。$k \ge 1$ のとき $\varphi(t) = \displaystyle\sum_{n=0}^{\infty}\frac{(i\eta t)^n}{n!}\,\Gamma\!\left(1 + \frac{n}{k}\right)$（$k = 1$ では $\lvert t \rvert < 1/\eta$） |

級数の係数は $E[X^n] = \eta^n\,\Gamma\!\left(1 + \frac{n}{k}\right)$ です。ワイブル分布は母関数より**分布関数** $F(x) = 1 - \exp[-(x/\eta)^k]$ のほうがずっと簡単なので、計算には分布関数を使うのがふつうです。

#### なぜ分布関数が $1 - \exp\!\left[-\left(\frac{x}{\eta}\right)^k\right]$ になるのか

ひとことで言うと、**故障率（ハザード）が時間のべき乗 $x^{k-1}$ で変わる寿命分布**だからです。以下の3通りの見方で理解できます（生存関数 $S(x) = 1 - F(x) = \exp\!\left[-\left(\frac{x}{\eta}\right)^k\right]$ で考えます）。

**見方1：故障率（ハザード）から作る**

ハザード $h(x)$ は「時刻 $x$ まで残っているものが、次の瞬間に壊れる割合」です。次の短い時間 $dx$ で割合 $h(x)\,dx$ が壊れるので、

$$S(x + dx) = S(x)\bigl(1 - h(x)\,dx\bigr) \quad\Longrightarrow\quad S'(x) = -h(x)\,S(x) \quad\Longrightarrow\quad S(x) = \exp\!\left(-\int_0^x h(t)\,dt\right)$$

| ハザード $h(x)$ | 累積 $\int_0^x h$ | 生存関数 $S(x)$ | 分布 |
| --- | --- | --- | --- |
| 一定 $\lambda$ | $\lambda x$ | $e^{-\lambda x}$ | 指数分布 |
| $\dfrac{k}{\eta}\left(\dfrac{x}{\eta}\right)^{k-1}$（べき乗） | $\left(\dfrac{x}{\eta}\right)^k$ | $\exp\!\left[-\left(\dfrac{x}{\eta}\right)^k\right]$ | **ワイブル分布** |

つまり、**指数分布の「故障率一定」を「故障率が時間のべき乗」に一般化したもの**で、$\exp$ の中の $\left(\frac{x}{\eta}\right)^k$ はハザードを積分した結果です。$k < 1$ ならハザードは減少（初期故障）、$k = 1$ で一定（偶発故障）、$k > 1$ で増加（摩耗故障）となり、上の「用途」の3分類（バスタブ曲線）に対応します。

**見方2：最も弱い部分で壊れる（Weibull 本人の発想）**

鎖は**一番弱い輪**が切れたときに切れます。材料を $n$ 個の小さな部分に分け、各部分が荷重 $x$ で壊れる確率を $\frac{c\,x^k}{n}$（小さい荷重では荷重のべき乗に比例）とすると、全体が壊れないのは $n$ 個すべてが壊れないときなので、

$$S(x) = \left(1 - \frac{c\,x^k}{n}\right)^n \xrightarrow{n\to\infty} e^{-c\,x^k}$$

（[極限の公式まとめ](../極限/極限の公式まとめ.md) の $\left(1 + \frac{x}{n}\right)^n \to e^x$）。$c = \eta^{-k}$ とおけばワイブル分布です。

> [!NOTE]
> 「たくさんの部分のうち最小の値（最も弱いもの）の分布」として出てくるので、ワイブル分布は**極値分布**の一種でもあります。

**見方3：指数分布の時間軸をゆがめたもの**

$X \sim Exp(1)$ なら $\eta X^{1/k} \sim W(k, \eta)$ です（冒頭の関係表）。言い換えると、**$\left(\frac{x}{\eta}\right)^k$ という「ゆがんだ時計」で測ると寿命が指数分布になる**ということです。$k > 1$ なら時間がたつほど時計が速く進む（老化が加速する）、$k < 1$ なら時計がだんだん遅くなる、というイメージです。

### 3-6. ベータ分布 $Be(\alpha, \beta)$

- **名前の由来**：確率密度関数の全体を $1$ にするための定数に**ベータ関数** $B(\alpha, \beta)$ が出てくるから。
- **用途**：**$0$ から $1$ の間の値（確率・割合）** のモデル。
  - ベイズ統計で、二項分布の成功確率 $p$ の**共役事前分布**（事前分布 $Be(\alpha, \beta)$ に「$n$ 回中 $k$ 回成功」を観測すると、事後分布は $Be(\alpha + k, \beta + n - k)$）
  - 一様分布の**順序統計量**（$n$ 個中の小さい方から $j$ 番目は $Be(j, n-j+1)$）
  - 広告のクリック率、打率、プロジェクトの進捗率など

| | 式 |
| --- | --- |
| 確率密度関数 | $f(x) = \dfrac{x^{\alpha-1}(1-x)^{\beta-1}}{B(\alpha, \beta)} \quad (0 < x < 1)$ |
| 確率母関数 | （ふつう使わない。形式的には $G(s) = M(\log s)$） |
| 積率母関数 | $M(t) = {}_1F_1(\alpha;\ \alpha+\beta;\ t) = 1 + \displaystyle\sum_{n=1}^{\infty}\left(\prod_{r=0}^{n-1}\frac{\alpha + r}{\alpha + \beta + r}\right)\frac{t^n}{n!}$ |
| 特性関数 | $\varphi(t) = {}_1F_1(\alpha;\ \alpha+\beta;\ it)$ |

${}_1F_1$ はクンマーの合流型超幾何関数です。級数の係数 $\prod_{r=0}^{n-1}\frac{\alpha+r}{\alpha+\beta+r}$ は $E[X^n]$ そのものです。$0 < X < 1$ で値が有界なので、積率母関数はすべての $t$ で存在します。$Be(1, 1)$ は一様分布 $U(0, 1)$ です。

## 4. 極限（近似）関係の数値例

![極限（近似）関係の数値例](./images/distribution_limits.png)

| 近似 | 使ってよい目安 | 理由（母関数で見ると） |
| --- | --- | --- |
| 超幾何 → 二項 | $n$ が $N$ の1割以下くらい | 取り出しても箱の中の割合がほとんど変わらない |
| 二項 → ポアソン | $n$ が大きく $p$ が小さい（例：$n \ge 50$、$np \le 5$） | $(1 + p(s-1))^n \to e^{\lambda(s-1)}$（$np = \lambda$） |
| 二項 → 正規 | $np$ と $nq$ がどちらも5以上くらい | 中心極限定理 |
| ポアソン → 正規 | $\lambda$ が大きい（例：$\lambda \ge 10$） | 中心極限定理（$Po(\lambda)$ は $Po(1)$ を $\lambda$ 個足したもの） |

二項分布からポアソン分布への極限は、確率母関数で見ると高校数学の極限 $\left(1 + \frac{x}{n}\right)^n \to e^x$ そのものです。

$$
G_{B(n, \lambda/n)}(s) = \left(1 + \frac{\lambda(s-1)}{n}\right)^n \xrightarrow{n \to \infty} e^{\lambda(s-1)} = G_{Po(\lambda)}(s)
$$

## 5. 覚え方のコツ

- **「独立な和 ⇔ 母関数の積」**：二項＝ベルヌーイの $n$ 乗、負の二項＝幾何の $r$ 乗、ガンマ＝指数の $\alpha$ 乗。母関数がべき乗の形になっている分布は「何かの和」です。
- **離散と連続のペア**：幾何分布 ↔ 指数分布（1回目までの待ち）、負の二項分布 ↔ ガンマ分布（$r$ 回目までの待ち）。どちらも無記憶性・和の関係が対応しています。
- **名前の由来は3パターン**：
  - 人名：ポアソン、ワイブル（正規分布の別名「ガウス分布」も）
  - 数式の形：二項（二項定理）、負の二項（負の指数の二項展開）、幾何（等比数列）、超幾何（超幾何級数）、指数（指数関数）
  - 正規化定数の関数：ガンマ（ガンマ関数）、ベータ（ベータ関数）

  カイ二乗は記号 $\chi^2$ から、正規は「ふつうに現れる」という意味からです。
