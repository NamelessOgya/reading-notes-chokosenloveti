# 条件付き分散の公式

## 結論（3行まとめ）

1. **全分散の公式：$V[Y] = E\bigl[V[Y \mid X]\bigr] + V\bigl[E[Y \mid X]\bigr]$。** 全体のばらつきは、「群の中のばらつきの平均」と「群の平均どうしのばらつき」の和に分けられます。
2. **その土台は全期待値の法則 $E[Y] = E\bigl[E[Y \mid X]\bigr]$ です。** 「$X$ を固定して平均をとり、あとで $X$ について平均をとる」と、全体の平均になります。
3. **使いどころは「2段階で決まる確率変数」です。** ランダムな個数の和、ポアソン分布の間引き、ポアソン-ガンマ混合（過分散）などで、分散がすぐ求まります。

---

## 1. 条件付き期待値と条件付き分散

### 1-1. 定義

$X$ の値を $x$ に固定したときの $Y$ の平均・分散を、それぞれ条件付き期待値・条件付き分散といいます。

$$
E[Y \mid X = x], \qquad V[Y \mid X = x] = E\bigl[(Y - E[Y \mid X = x])^2 \mid X = x\bigr]
$$

分散の公式 $V[Y] = E[Y^2] - (E[Y])^2$ と同じ形が、条件付きでも成り立ちます。

$$
V[Y \mid X] = E[Y^2 \mid X] - \bigl(E[Y \mid X]\bigr)^2
$$

右辺の第2項を移項すると、**$Y$ の2乗の条件付き期待値**を表す次の形になります（3-2 で使います）。

$$
E[Y^2 \mid X] = V[Y \mid X] + \bigl(E[Y \mid X]\bigr)^2
$$

### 1-2. $E[Y \mid X]$ は「$X$ の関数」＝確率変数

$g(x) = E[Y \mid X = x]$ とおいて、$x$ のところに確率変数 $X$ を代入したもの $g(X)$ を $E[Y \mid X]$ と書きます。

- **$X = x$ と固定した式**：ただの数（$x$ の関数の値）。
- **$E[Y \mid X]$ と書いた式**：$X$ が変わると値が変わる**確率変数**。

したがって $E[Y \mid X]$ や $V[Y \mid X]$ に対して、さらに期待値 $E[\cdot]$ や分散 $V[\cdot]$ をとることができます。公式の左辺と右辺に $E[V[Y \mid X]]$ や $V[E[Y \mid X]]$ という入れ子が出てくるのは、このためです。

### 1-3. 例：サイコロを振って、その回数だけコインを投げる

サイコロを振って出た目を $N$ とし、コインを $N$ 回投げたときの表の回数を $Y$ とします。

- $N$ を固定すると $Y \mid N \sim B(N, \frac12)$。
- したがって $E[Y \mid N] = \dfrac{N}{2}$、$V[Y \mid N] = \dfrac{N}{4}$。

## 2. 全期待値の法則（繰り返し期待値の法則）

### 2-1. 主張

$$
\boxed{\ E[Y] = E\bigl[E[Y \mid X]\bigr]\ }
$$

### 2-2. 証明（離散の場合）

$$
E[Y] = \sum_y y\,P(Y=y) = \sum_y y \sum_x P(Y=y \mid X=x)\,P(X=x)
= \sum_x \underbrace{\left(\sum_y y\,P(Y=y \mid X=x)\right)}_{E[Y \mid X=x]} P(X=x)
$$

最後は $E[Y \mid X = x]$ を $P(X=x)$ で重み付けして足したもの、つまり $E\bigl[E[Y \mid X]\bigr]$ です。

### 2-3. 意味と例

「クラスごとの平均点を、クラスの人数で重み付けして平均すると、学年全体の平均点になる」という当たり前の話です。

**例（1-3 の続き）**：サイコロの目の平均は $E[N] = \frac72$ なので、

$$
E[Y] = E\!\left[\frac{N}{2}\right] = \frac{7}{4}
$$

## 3. 全分散の公式

### 3-1. 主張

$$
\boxed{\ V[Y] = \underbrace{E\bigl[V[Y \mid X]\bigr]}_{\text{群の中のばらつきの平均}} + \underbrace{V\bigl[E[Y \mid X]\bigr]}_{\text{群の平均どうしのばらつき}}\ }
$$

### 3-2. 証明

分散の公式 $V[Y] = E[Y^2] - (E[Y])^2$ から出発します。

**① $E[Y^2]$ に全期待値の法則を使う**

$$
E[Y^2] = E\bigl[E[Y^2 \mid X]\bigr] = E\Bigl[V[Y \mid X] + \bigl(E[Y \mid X]\bigr)^2\Bigr]
$$

（$E[Y^2 \mid X] = V[Y \mid X] + (E[Y \mid X])^2$ は、1-1 の $V[Y \mid X] = E[Y^2 \mid X] - (E[Y \mid X])^2$ を移項した形です。）

**② $(E[Y])^2$ にも全期待値の法則を使う**

$$
\bigl(E[Y]\bigr)^2 = \Bigl(E\bigl[E[Y \mid X]\bigr]\Bigr)^2
$$

**③ 差をとる**

$$
V[Y] = E\bigl[V[Y \mid X]\bigr] + \underbrace{E\Bigl[\bigl(E[Y \mid X]\bigr)^2\Bigr] - \Bigl(E\bigl[E[Y \mid X]\bigr]\Bigr)^2}_{= V\bigl[E[Y \mid X]\bigr]}
$$

最後の括弧は、確率変数 $E[Y \mid X]$ の「2乗の平均 − 平均の2乗」、つまり分散です。$\blacksquare$

### 3-3. 意味：群内ばらつき ＋ 群間ばらつき

$X$ で $Y$ をいくつかの群に分けたとき、

| 項 | 意味 |
| --- | --- |
| $E[V[Y \mid X]]$ | 各群の**中**のばらつきを、群の大きさで重み付け平均したもの（**群内変動**） |
| $V[E[Y \mid X]]$ | 各群の**平均どうし**のばらつき（**群間変動**） |

分散分析（ANOVA）の「全変動 ＝ 群内変動 ＋ 群間変動」と同じ分解です。

### 3-3'. 図で見る

![混合分布での群内ばらつきと群間ばらつき。右は4つの例での内訳](./images/total_variance.png)

- **左**：$X = A$ なら $N(0,1)$、$X = B$ なら $N(4,1)$（確率は $\frac12$ ずつ）の混合分布です。
  - 群の中のばらつき：どちらも分散 $1$ なので、$E[V[Y \mid X]] = 1$。
  - 群の平均 $0$ と $4$ のばらつき：平均 $2$ から $\pm2$ なので $V[E[Y \mid X]] = 4$。
  - 合計 $V[Y] = 1 + 4 = 5$。
- **右**：4つの例（4 で扱います）で、全分散のうち群内・群間がそれぞれ何％かを表しています。

### 3-4. 特別な場合

- **$X$ と $Y$ が独立**：$E[Y \mid X] = E[Y]$（定数）なので $V[E[Y \mid X]] = 0$、$V[Y \mid X] = V[Y]$。公式は $V[Y] = V[Y]$ になります。
- **$Y$ が $X$ の関数**：$V[Y \mid X] = 0$ なので $V[Y] = V[E[Y \mid X]] = V[Y]$。
- **常に** $E[V[Y \mid X]] \le V[Y]$：条件を付けると、ばらつきは**平均的には**減ります。ただし特定の $X = x$ では $V[Y \mid X = x] > V[Y]$ となることもあります。

## 4. 例

### 4-1. サイコロとコイン（1-3 の続き）

$E[V[Y \mid N]] = E\!\left[\dfrac{N}{4}\right] = \dfrac{7}{8}$、$V[E[Y \mid N]] = V\!\left[\dfrac{N}{2}\right] = \dfrac{1}{4}\cdot\dfrac{35}{12} = \dfrac{35}{48}$（サイコロの分散は $\frac{35}{12}$）なので、

$$
V[Y] = \frac78 + \frac{35}{48} = \frac{42 + 35}{48} = \frac{77}{48} \approx 1.604
$$

### 4-2. ランダムな個数の和（複合分布）

$X_1, X_2, \dots$ が独立同分布（平均 $\mu$、分散 $\sigma^2$）で、個数 $N$ もランダム（$X_i$ と独立）とします。

$$
Y = X_1 + \cdots + X_N
$$

$N$ を固定すると、$Y$ は $N$ 個の独立な和なので $E[Y \mid N] = N\mu$、$V[Y \mid N] = N\sigma^2$ です。

$$
E[Y] = E[N]\,\mu, \qquad
V[Y] = E[N]\,\sigma^2 + V[N]\,\mu^2
$$

> **例**：$N \sim Po(\lambda)$ のとき $E[N] = V[N] = \lambda$ なので、$V[Y] = \lambda(\sigma^2 + \mu^2) = \lambda\,E[X_1^2]$。
> 保険金の総額（事故件数がポアソン分布、1件の金額が $X_i$）などに使います。

### 4-3. ポアソン分布の間引き

$N \sim Po(\lambda)$ 個の客が来て、それぞれ独立に確率 $p$ で購入するとします。購入者数 $Y$ について、$Y \mid N \sim B(N, p)$ なので、

$$
E[Y] = E[Np] = \lambda p, \qquad
V[Y] = \underbrace{E[Np(1-p)]}_{\lambda p(1-p)} + \underbrace{V[Np]}_{p^2\lambda} = \lambda p
$$

平均も分散も $\lambda p$ で、$Y \sim Po(\lambda p)$ と整合します（実際にそうなります）。

### 4-4. ポアソン-ガンマ混合（過分散）

ポアソン分布の平均 $\Theta$ 自体がばらつくとします：$\Theta \sim Ga(\alpha, \lambda)$、$Y \mid \Theta \sim Po(\Theta)$。

- $E[Y \mid \Theta] = \Theta$、$V[Y \mid \Theta] = \Theta$。
- $E[\Theta] = \dfrac{\alpha}{\lambda}$、$V[\Theta] = \dfrac{\alpha}{\lambda^2}$。

$$
E[Y] = \frac{\alpha}{\lambda}, \qquad
V[Y] = \underbrace{E[\Theta]}_{\alpha/\lambda} + \underbrace{V[\Theta]}_{\alpha/\lambda^2} = \frac{\alpha}{\lambda} + \frac{\alpha}{\lambda^2}
$$

**分散が平均より大きく（$V[Y] > E[Y]$）なります**（過分散）。この $Y$ は**負の二項分布**に従うことが知られています（[代表的な確率分布](./代表的な確率分布.md) の 2-4）。「ポアソン分布よりばらつくカウントデータ」のモデルとして負の二項分布が使われる理由は、この混合の構造にあります。

### 4-5. 2変量正規分布

$(X, Y)$ が2変量正規分布（相関係数 $\rho$）のとき、$X = x$ を与えた $Y$ の条件付き分布は正規分布で、

$$
E[Y \mid X] = \mu_Y + \rho\frac{\sigma_Y}{\sigma_X}(X - \mu_X), \qquad
V[Y \mid X] = \sigma_Y^2(1 - \rho^2)
$$

（条件付き分散は $X$ によらず一定です。）全分散の公式を確かめると、

$$
\underbrace{\sigma_Y^2(1-\rho^2)}_{E[V[Y \mid X]]} + \underbrace{\rho^2\frac{\sigma_Y^2}{\sigma_X^2}\cdot\sigma_X^2}_{V[E[Y \mid X]]} = \sigma_Y^2
$$

となり、ぴったり合います。[共分散と相関係数](./共分散と相関係数.md)の 5 の $V[Y](1-\rho^2)$ と同じ式です。

### 4-6. 数値で確認

シミュレーション（100万回）の結果は、公式とよく合います。

| 例 | 公式 | シミュレーション |
| --- | --- | --- |
| 混合分布（$N(0,1)$ と $N(4,1)$） | $V[Y] = 5$ | $4.994$ |
| ランダム和（$N \sim Po(4)$、$X_i \sim U(0,6)$） | $V[Y] = 4\cdot3 + 4\cdot9 = 48$ | $48.17$（20万回） |
| 間引き（$\lambda=10$、$p=0.3$） | $V[Y] = 3$ | $2.998$ |
| ポアソン-ガンマ（$\alpha=3$、$\lambda=1$） | $V[Y] = 6$ | $5.978$ |
| 2変量正規（$\rho=0.6$）、$X \approx 1$ のとき | $V[Y \mid X] = 0.64$ | $0.644$ |

## 5. 予測の観点：$E[Y \mid X]$ が最良の予測

$X$ から $Y$ を予測する関数 $h(X)$ のうち、2乗誤差 $E[(Y - h(X))^2]$ を最小にするのは $h(X) = E[Y \mid X]$ です。

$$
E\bigl[(Y - h(X))^2\bigr] = E\bigl[V[Y \mid X]\bigr] + E\Bigl[\bigl(E[Y \mid X] - h(X)\bigr)^2\Bigr]
$$

右辺の第2項は $h = E[Y \mid X]$ のとき $0$ になるので、**最小の誤差は $E[V[Y \mid X]]$**、つまり全分散の公式の第1項です。

- **$V[E[Y \mid X]]$**：$X$ で説明できるばらつき。
- **$E[V[Y \mid X]]$**：$X$ では説明できない（予測できずに残る）ばらつき。
- **相関比** $\dfrac{V[E[Y \mid X]]}{V[Y]}$：$X$ で説明できる割合。条件付き期待値が直線なら $\rho^2$（決定係数）と一致します。

## 6. 試験での使い方

- **2段階で決まる確率変数**（個数がランダム、パラメータがランダム、など）を見たら、全期待値・全分散の公式を使う。
  1. 外側の変数（$X$、$N$、$\Theta$）を固定した条件付き期待値・条件付き分散を求める。
  2. $E[V[Y \mid X]] + V[E[Y \mid X]]$ を計算する。
- **よくある間違い**：
  - $V[E[Y \mid X]]$ の項を落とす（$E[V[Y \mid X]]$ だけだと全分散より小さくなる）。
  - ランダム和の分散で $V[N]\mu^2$ を忘れる。
  - $V[Y \mid X]$ を定数だと思う（一般には $X$ の関数で、$E[\cdot]$ を取る必要がある）。
- **共分散版**（全共分散の公式）：$\mathrm{Cov}(X, Y) = E[\mathrm{Cov}(X, Y \mid Z)] + \mathrm{Cov}\bigl(E[X \mid Z], E[Y \mid Z]\bigr)$。

---

## まとめ

- **全期待値の法則**：$E[Y] = E[E[Y \mid X]]$。
- **全分散の公式**：$V[Y] = E[V[Y \mid X]] + V[E[Y \mid X]]$（群内 ＋ 群間）。
- **証明**：$E[Y^2]$ と $(E[Y])^2$ のそれぞれに全期待値の法則を使うだけ。
- **応用**：ランダム和 $V[Y] = E[N]\sigma^2 + V[N]\mu^2$、間引き、ポアソン-ガンマ混合（過分散・負の二項分布）、2変量正規。
- **意味**：$E[Y \mid X]$ は最良の予測で、$E[V[Y \mid X]]$ は予測しきれない分。
