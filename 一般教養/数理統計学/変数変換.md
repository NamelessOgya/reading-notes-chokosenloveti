# 変数変換（密度と積率母関数）

## 結論（3行まとめ）

1. **密度の変数変換には補正 $\left|\frac{dx}{dy}\right|$ が必要です。** 密度は「単位長さあたりの確率」なので、目盛りが伸び縮みすると値が変わるからです。分布関数を求めてから微分すれば、この補正は自動的に出てきます。
2. **積率母関数の変数変換には補正は要りません。** 積率母関数は期待値 $E[e^{tY}]$ なので、元の $X$ の密度のまま $\int e^{t\,g(x)} f_X(x)\,dx$ を計算すれば求まります。
3. **ただし「$M_X(t)$ の $t$ を置き換えるだけ」で済むのは1次変換 $Y = aX + b$ のときだけです**（$M_Y(t) = e^{bt}M_X(at)$）。$Y = X^2$ のような変換では、積分を計算し直します。

---

## 1. 密度の変数変換

$X$ の密度 $f_X$ が分かっているとき、$Y = g(X)$ の密度 $f_Y$ を求めます。

### 1-1. 基本：分布関数を経由する

どんな変換でも使える基本の手順は次の2ステップです。

1. **$Y$ の分布関数** $F_Y(y) = P(Y \le y)$ を、$X$ の確率に書き直して求める。
2. **$y$ で微分**して $f_Y(y) = F_Y'(y)$ を得る。

**例：$Y = aX + b$（$a > 0$）**

$$
F_Y(y) = P(aX + b \le y) = P\!\left(X \le \frac{y - b}{a}\right) = F_X\!\left(\frac{y - b}{a}\right)
$$

合成関数の微分で、中身の微分 $\frac{1}{a}$ が出てきます。

$$
f_Y(y) = \frac{1}{a}\, f_X\!\left(\frac{y - b}{a}\right)
$$

$a < 0$ のときは不等号の向きが逆になって $F_Y(y) = 1 - F_X\!\left(\frac{y-b}{a}\right)$ となり、微分すると $-\frac{1}{a} = \frac{1}{\lvert a \rvert}$ が出ます。まとめると $f_Y(y) = \dfrac{1}{\lvert a \rvert} f_X\!\left(\dfrac{y - b}{a}\right)$ です。

### 1-2. 公式：$g$ が単調な場合

$g$ が単調（ずっと増加、またはずっと減少）で、逆関数を $x = g^{-1}(y)$ とすると、1-1 と同じ計算で

$$
\boxed{\ f_Y(y) = f_X\bigl(g^{-1}(y)\bigr)\left|\frac{dx}{dy}\right|\ }
$$

となります。$\left|\frac{dx}{dy}\right|$ が**補正（ヤコビアン）**です。絶対値は、減少関数のとき不等号の向きが逆になって出てくるマイナスを打ち消すためのものです。

### 1-3. $g$ が単調でない場合：$Y = X^2$

$X \sim N(0, 1)$、$Y = X^2$ とします。$y > 0$ について、$X^2 \le y$ となるのは $-\sqrt{y} \le X \le \sqrt{y}$ のときなので、

$$
F_Y(y) = P(-\sqrt{y} \le X \le \sqrt{y}) = \Phi(\sqrt{y}) - \Phi(-\sqrt{y}) = 2\Phi(\sqrt{y}) - 1
$$

（最後の等号は、正規分布が左右対称なので $\Phi(-a) = 1 - \Phi(a)$ となることを使っています）。$y$ で微分すると、$(\sqrt{y})' = \frac{1}{2\sqrt{y}}$ が補正として出てきます。

$$
f_Y(y) = 2\varphi(\sqrt{y})\cdot\frac{1}{2\sqrt{y}} = \frac{1}{\sqrt{2\pi y}}\, e^{-y/2}
$$

これは自由度1のカイ二乗分布 $\chi^2(1) = Ga\left(\frac12, \frac12\right)$ です（[代表的な確率分布](./代表的な確率分布.md) の 3-3）。

> [!NOTE]
> 単調でない変換では、**$y$ に対応する $x$ が複数ある**（ここでは $\pm\sqrt{y}$）ので、それぞれの寄与を足し合わせます。$2\varphi(\sqrt{y})$ の「$2$」は、$+\sqrt{y}$ 側と $-\sqrt{y}$ 側の2つ分です。

### 1-4. なぜ補正が必要なのか

![1次変換では密度が横に伸びて高さが半分になり、X² では0の近くに押し込められて密度が高くなる](./images/change_of_variables_density.png)

- **左（1次変換 $Y = 2X + 1$）**：$X$ の区間 $[0, 0.5]$ は $Y$ の区間 $[1, 2]$ に移り、**幅が2倍**になります。確率（面積）は変わらないので、**高さ（密度）は半分**になります。この「半分」が補正 $\left|\frac{dx}{dy}\right| = \frac12$ です。
- **右（$Y = X^2$）**：$0$ に近い $X$ は、2乗するとさらに $0$ のごく近くに押し込められます（例：$0.1 \to 0.01$）。幅が縮むので密度は高くなり、$y \to 0$ で無限大になります。シミュレーションのヒストグラムと、変数変換で求めた式がぴったり重なっています。

**密度は「単位長さあたりの確率」なので、目盛りの伸び縮みに合わせて補正が必要**、ということです。

## 2. 積率母関数の変数変換

### 2-1. 補正は要らない

$Y = g(X)$ の積率母関数は、定義どおりに書くと

$$
\boxed{\ M_Y(t) = E\bigl[e^{tY}\bigr] = E\bigl[e^{t\,g(X)}\bigr] = \int e^{t\,g(x)}\, f_X(x)\, dx\ }
$$

$X$ の値ごとに $e^{t\,g(x)}$ を計算して、**$X$ の確率で重み付け平均するだけ**です。$Y$ の密度 $f_Y$ を求める必要がないので、補正は出てきません。

### 2-2. 1次変換なら「置き換えるだけ」

$Y = aX + b$ なら、

$$
M_Y(t) = E\bigl[e^{t(aX + b)}\bigr] = e^{bt}\, E\bigl[e^{(at)X}\bigr] = e^{bt}\, M_X(at)
$$

**$M_X$ の中身を $at$ に置き換えて、$e^{bt}$ を掛けるだけ**です。

> 例：$X \sim N(0, 1)$（$M_X(t) = e^{t^2/2}$）のとき、$Y = \sigma X + \mu$ は
> $$M_Y(t) = e^{\mu t}\, e^{\sigma^2 t^2/2}$$
> となり、$N(\mu, \sigma^2)$ の積率母関数が得られます。

### 2-3. 非線形の変換では積分し直す

$Y = X^2$ の場合、$M_Y(t) = E[e^{tX^2}]$ は $M_X(\text{何か})$ の形には**なりません**。元の密度で積分を計算し直します。

> 例：$X \sim N(0, 1)$ のとき、指数をまとめると
> $$M_{X^2}(t) = \int_{-\infty}^{\infty} e^{tx^2}\cdot\frac{1}{\sqrt{2\pi}}e^{-x^2/2}\, dx = \int_{-\infty}^{\infty} \frac{1}{\sqrt{2\pi}}\, e^{-(1-2t)x^2/2}\, dx = (1 - 2t)^{-1/2} \quad \left(t < \tfrac12\right)$$
> 最後の等号は、分散 $\frac{1}{1-2t}$ の正規分布の密度 $\frac{\sqrt{1-2t}}{\sqrt{2\pi}}e^{-(1-2t)x^2/2}$ の積分が $1$ になることを使っています。

結果の $(1 - 2t)^{-1/2}$ は $Ga\left(\frac12, \frac12\right) = \chi^2(1)$ の積率母関数で、**1-3 の密度の計算と同じ結論が、ヤコビアンなしで得られています**。

### 2-4. おまけ：独立な和は掛け算

$X, Y$ が独立なら $M_{X+Y}(t) = M_X(t)\,M_Y(t)$ です。密度で和の分布を求めると畳み込み積分が必要になるので、和の分布を求めるときは積率母関数のほうが圧倒的に楽です（[連続性定理](./連続性定理.md) の 3 も参照）。

---

## 3. 2つのやり方がつじつまが合う理由

$f_Y$ を使って $y$ で積分しても、$f_X$ を使って $x$ で積分しても、期待値は同じになります。$y = g(x)$ と置換すると、

$$
\int h(y)\, f_Y(y)\, dy
= \int h(g(x))\, \underbrace{f_X(x)\left|\frac{dx}{dy}\right|}_{f_Y(y)}\, \underbrace{\left|\frac{dy}{dx}\right| dx}_{dy}
= \int h(g(x))\, f_X(x)\, dx
$$

**密度の補正 $\left|\frac{dx}{dy}\right|$ と、置換積分の $\left|\frac{dy}{dx}\right|$ が打ち消し合う**ので、$x$ のまま計算すれば補正が要らない、というわけです。$h(y) = e^{ty}$ とすれば積率母関数の場合になります。

## 4. 比較と使い分け

| | 密度 $f_Y$ | 積率母関数 $M_Y$ |
| --- | --- | --- |
| 正体 | 単位長さあたりの確率 | 期待値 $E[e^{tY}]$ |
| 補正 | $\left\lvert\frac{dx}{dy}\right\rvert$ が**必要** | **不要** |
| 1次変換 $Y = aX + b$ | $\dfrac{1}{\lvert a \rvert}\, f_X\!\left(\dfrac{y - b}{a}\right)$ | $e^{bt}\, M_X(at)$（置き換えるだけ） |
| 一般の $Y = g(X)$ | 分布関数を経由して微分（単調でなければ枝ごとに足す） | $\int e^{t\,g(x)} f_X(x)\,dx$ を計算し直す |
| 独立な和 $X + Y$ | 畳み込み積分（大変） | 掛け算（簡単） |

> [!TIP]
> **試験での使い分け**
> - 「**$Y$ の分布を求めよ（何分布か答えよ）**」→ 積率母関数を計算して、既知の分布の積率母関数と見比べるのが楽なことが多いです（積率母関数が一致すれば分布も一致します）。
> - 「**$Y$ の密度を求めよ**」→ 分布関数を経由する方法（1-1）が確実です。公式（1-2）を使うときは、$g$ が単調かどうかと絶対値を忘れないこと。

---

## まとめ

- **密度**は単位長さあたりの確率なので、変数変換では補正 $\left|\frac{dx}{dy}\right|$ が必要。分布関数を求めて微分すれば自動的に出てくる。単調でない変換では枝ごとに足す。
- **積率母関数**は期待値なので補正は不要。$\int e^{t\,g(x)} f_X(x)\,dx$ を計算すればよい。
- **1次変換**なら $M_Y(t) = e^{bt}M_X(at)$ と置き換えるだけ。**非線形**なら積分し直す。
- 2つのやり方が一致するのは、密度の補正と置換積分の因子が打ち消し合うから。
